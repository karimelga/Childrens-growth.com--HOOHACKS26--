# Contract: AI Explanation API

**Endpoint**: `POST /api/explain`
**Owner**: `server/index.js` (Express proxy)
**Consumer**: `src/components/AIExplanation.jsx`
**Date**: 2026-03-22

---

## Purpose

Accepts a structured neighborhood context from the browser and returns a plain-language
3–4 sentence explanation generated by Claude. This endpoint exists solely to keep the
Anthropic API key out of the browser (Constitution Principle II).

---

## Request

**Method**: `POST`
**Path**: `/api/explain`
**Content-Type**: `application/json`

### Body Schema

```json
{
  "zip": "22101",
  "label": "McLean",
  "archetype": "The Expensive Suburb",
  "age_group": "child",
  "priorities": {
    "education": 90,
    "social_development": 50,
    "safety": 80,
    "infrastructure": 40
  },
  "scores": {
    "education": 94,
    "social_development": 72,
    "safety": 91,
    "infrastructure": 74,
    "final": 86
  },
  "budget_fit": "affordable"
}
```

### Field Rules

| Field | Type | Required | Constraints |
|-------|------|----------|-------------|
| `zip` | string | Yes | One of the five valid ZIP codes |
| `label` | string | Yes | Human-readable neighborhood name |
| `archetype` | string | Yes | Neighborhood archetype string |
| `age_group` | string | Yes | `"newborn"` \| `"toddler"` \| `"child"` |
| `priorities.*` | number | Yes | Each 0–100 |
| `scores.*` | number | Yes | Each 0–100; `final` is the composite |
| `budget_fit` | string | Yes | `"affordable"` \| `"over budget"` |

---

## Response

**Content-Type**: `application/json`

### Success (200)

```json
{
  "explanation": "McLean is a strong match for your family's priorities..."
}
```

| Field | Type | Description |
|-------|------|-------------|
| `explanation` | string | 3–4 sentence plain-language explanation from Claude |

### Error — Invalid Request (400)

```json
{
  "error": "Missing required field: zip"
}
```

### Error — AI Service Unavailable (502)

```json
{
  "error": "AI explanation service unavailable. Please try again."
}
```

### Error — Server Error (500)

```json
{
  "error": "Unexpected server error."
}
```

---

## Prompt Template (server-side, not exposed to browser)

The server constructs the following prompt before calling Claude:

```
You are analyzing a neighborhood score for a parent using the Child Development Score app.

ZIP Code: {label} ({zip}) — {archetype}
Child Age Group: {age_group}
User Priorities (0-100): Education={education}, Social={social}, Safety={safety}, Infrastructure={infra}

Calculated Scores:
- Education: {edu_score}/100
- Social Development: {social_score}/100
- Safety: {safe_score}/100
- Infrastructure: {infra_score}/100
- FINAL Child Development Score: {final_score}/100

Budget fit: {budget_fit}

In 3-4 sentences, explain why this neighborhood scored the way it did for THIS specific
family's priorities and child's age. Highlight the biggest trade-off they should be aware of.
Be warm but honest. Do not use bullet points.
```

---

## Behavior Contracts

- The server MUST NOT log or store any `priorities`, `scores`, or personal context from the
  request body.
- The `ANTHROPIC_API_KEY` MUST be read from `process.env.ANTHROPIC_API_KEY` and MUST NOT
  appear anywhere in the response or logs.
- If Claude returns a response longer than 6 sentences, the server MUST pass it through
  as-is (truncation is the UI's concern if needed).
- The server MUST return a 502 with the error body above if the Anthropic SDK throws any
  exception, so the browser can display a graceful fallback.
- Response time target: < 10 seconds under normal conditions.
